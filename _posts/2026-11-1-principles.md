# Principles

A list of principles that I would like to but seldom manage to live by. 
Nonetheless the version of me that I would like to become remembers these 
things.

- Don't fool yourself
- You get out, what you put in
- Don't compare yourself to others
- Just go to bed, don't try to "save" days
- Try to set yourself up for success
- Forgive yourself
- Be ambitious
- Live in a way which minimises regret

I'm sure I will expand this and maybe add or edit this list in time, but this 
is just a start.
